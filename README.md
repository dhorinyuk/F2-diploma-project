# F2 Diploma Project

## Development of an Intelligent Web Platform for Vehicle Condition Analysis and Failure Prediction

Qualification project for the F2 Software Engineering specialty.

### Project Overview

The project is a web platform for centralized collection, storage, analysis and visualization of vehicle diagnostic and telemetry data.

The system is designed to detect anomalies in vehicle parameters and generate predictive risk estimates for potential technical failures.

### Architecture

The planned solution uses:

* REST API
* Event-Driven Architecture
* Service-Oriented / Microservice Architecture
* PostgreSQL
* Redis
* RabbitMQ
* Docker
* GitHub Actions
* Prometheus
* Grafana
